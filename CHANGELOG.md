# Changelog

## 0.1.0 (repository migration)

- Preserve the latest Miniator engine archive as the initial functional baseline.
- Add pinned dependencies, an independently buildable POSIX shared-memory addon,
  project commands, documentation and regression checks.
- Introduce a small subprocess-based public API, without claiming persistent
  cross-job browser sessions or unsupported features.
- No changes to the rendering optimization algorithm are intended by this migration.
