# Changelog

## 0.1.1

- Standardize the Miniator project namespace across the tracked code and documentation.
- Add repository checks for unexpected project identifiers and tracked third-party bundles.
- Keep rendering strategies, native shared-memory capture and conditional planner behavior intact.

## 0.1.0

- Establish the initial Git-tracked engine source, build scripts, CLI and Node.js process adapter.
- Build the POSIX shared-memory addon from source and generate browser bundles locally.
- Add the seven fixture corpus, lightweight tests, and development/benchmark tooling.

The 0.1.x releases are experimental development snapshots, not production API stability commitments.
